# Deployment-Manifeste

In diesem Verzeichnis liegen ausschließlich tatsächlich erzeugte,
maschinenlesbare Deployment-Manifeste.

Aktuell existiert kein Deployment. `scripts/deploy-reist.js` erzeugt nach einem
erfolgreichen, geprüften Base-Sepolia-Deployment die Datei
`base-sepolia.json`. Es werden keine Beispieladressen als echte Verträge
ausgegeben.

Ein Mainnet-Manifest darf erst nach den dokumentierten Release-Gates entstehen.
